# Сповіщення — план для Android

**Статус: ЗАПЛАНОВАНО, ще не реалізовано** (звук+вібрація — вже зроблено, див. нижче).
Записано 10.08.2026 за описом Кепа, чекає команди "Виконуй" на решту.

---

## Проблема зараз

Записи в "Мої сповіщення" з'являються лише якщо Capacitor реально спіймав push-подію на
пристрої. Якщо застосунок закритий/подія не спрацювала — запису нема або він порожній.

## Нова архітектура (спільна для всіх платформ)

1. При відправці повідомлення з адмінки — пишеться запис **напряму у Firestore** (нова
   колекція `notifications/{userId}/messages/{id}`) через внутрішній метод адмінки —
   незалежно від push.
2. Push шлеться **окремо**, тим самим Cloudflare Worker'ом (`euroclub-push-sender`) —
   паралельний виклик, не залежний від запису.

## Що специфічно для Android

### ✅ Зроблено (10.08): звук + вібрація
- Файл `android/app/src/main/res/raw/notification_sound.mp3` — власний звук сповіщення
  (наданий Кепом).
- Worker (`euroclub-push-worker.js`) шле в FCM payload:
  `android: { notification: { sound: 'notification_sound', default_vibrate_timings: true } }`
- **Технічний нюанс, важливо:** на Android 8+ звук/вібрація прив'язані до **notification
  channel**, а не до кожного push окремо — канал створюється ОДИН РАЗ з певними
  налаштуваннями і далі вони **незмінні** (навіть новий payload з іншим звуком не
  перезапише канал, якщо він уже існує на пристрої з іншими налаштуваннями). Якщо у
  когось із користувачів канал уже створився РАНІШЕ (до цього фіксу, без кастомного звуку)
  — новий звук у них **не запрацює**, доки не перевстановлять застосунок або Capacitor не
  створить канал з новим ID. Це не баг коду, а обмеження Android — тестувати варто на
  свіжому встановленні.

### ⬜ Бейдж на іконці застосунку (system badge)
Android підтримує бейдж на іконці (число на іконці застосунку на хоум-скріні) через
launcher-специфічні API — на відміну від iOS, це **не єдиний стандартний механізм**,
поведінка залежить від launcher'а виробника (Samsung, Xiaomi, стоковий Android тощо).
Потрібен окремий Capacitor-плагін (напр. `@capawesome/capacitor-badge` — підтримує і
Android, і iOS одним API) — **ще не встановлений у проєкті**.

### ⬜ Список "Мої сповіщення"
Читає нову Firestore-колекцію, показує тему в списку, тап відкриває деталі (тема + текст).

### ⬜ Бейдж на дзвінку (в UI застосунку)
Червоний кружечок з числом непрочитаних у нижній навігації — рахується з Firestore.
