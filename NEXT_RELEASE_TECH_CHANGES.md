## Список (з часу останнього релізу: Android 1.0.18 підготовлено / iOS Build 6, 09.08)

1. Виправлено читання `db.uidkey` при вході (нове поле бекенду, з фолбеком на старе `key`)
2. `useOrderPolling` тепер синхронізує ВЕСЬ масив замовлень з відповіді бекенду за раз
   (раніше — тільки одне замовлення, решта відкидалась)
3. Запис "живої сесії" юзера (`user_sessions/{userId}`) — технічна основа для адмінки
   (ретроактивне оновлення старих замовлень)
4. `order_registry` пише `backendAppPlatform`/`backendUserId` одразу при СТВОРЕННІ
   замовлення (раніше — тільки при пізнішому опитуванні)
5. *(наступний пункт — ціноутворення, у розробці)*
